# Taiga - Manual QA Testing Project

## Project Overview

This project presents a comprehensive manual QA testing process conducted on **Taiga**, a web-based project management platform.

The project focuses on functional testing, cross-browser testing, defect identification, test execution, and professional QA documentation.

The testing process was conducted independently, covering test case design, execution, defect reporting, results analysis, and preparation of a detailed Software Test Report (STR).

## Testing Scope

- Functional testing of the Taiga web application
- User interface and usability testing
- Positive and negative test scenarios
- Cross-browser testing using Google Chrome and Safari
- Defect identification, reporting, and classification
- Test execution analysis and documentation

## Bug Reporting

A total of **9 bug reports** were documented in Jira.

Each report includes relevant information such as reproduction steps, expected and actual results, severity, priority, and supporting evidence where applicable.

The project also includes defect analysis and graphical representations of severity and priority.

## Software Test Report (STR)

A comprehensive STR was prepared to document the manual testing process.

The report includes:

- Project introduction and application overview
- Testing scope
- Test tree and test coverage
- Test execution results
- Bug reports and supporting evidence
- Severity and priority charts
- Conclusions and recommendations
- Final project summary and closure
